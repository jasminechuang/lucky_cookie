# 🌟 星象命盤幸運餅乾 (Astrology Lucky Cookie)

融合星座命盤與東方流年運勢的專屬解籤網頁應用程式。

## 📖 專案簡介

「星象命盤幸運餅乾」是一個結合西方星座命盤解析與東方傳統流年運勢的互動式網頁工具。使用者可以設定自己的專屬星座與命盤資訊，透過每日抽籤與命盤日曆功能，探索每日的星象籤詩與運勢指引。

## ✨ 主要功能

- **個人化命盤設定**：支援設定與修改個人星座、元素（風象、火象、水象、土象）及守護星等基本資訊。
- **每日抽籤與籤詩**：提供專屬的幸運餅乾抽籤體驗，結合東方流年運勢解讀每日運勢。
- **命盤日曆檢視**：以月曆介面標記每日抽籤紀錄與有標記的日期，方便回顧與點擊查看當日星象籤詩。
- **紀錄重置管理**：提供清除所有紀錄與重置設定的功能，隨時重新開始。

## 🛠️ 技術架構

- **前端技術**：純 HTML / CSS / JavaScript 實作。
- **資料儲存**：利用瀏覽器本地儲存（LocalStorage）記錄使用者設定與每日抽籤狀態。
